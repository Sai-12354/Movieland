# 🎬 MovieLand

MovieLand is a simple movie search web application built using React.  
It allows users to search for movies and view basic details like title and poster using the OMDb API.

This project was built as part of my learning journey to understand React, components, and API usage.

---

## 🚀 Features
- Search movies by name  
- Display movie posters and titles  
- Clean and simple user interface  
- Responsive layout  

---

## 🛠️ Technologies Used
- React.js  
- JavaScript  
- HTML  
- CSS  
- OMDb API  

---
